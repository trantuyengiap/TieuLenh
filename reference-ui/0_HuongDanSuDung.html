1
Mở màn hình LED lên màn hình lớn
Double-click 2_ManHinhLED.html → nhấn F11 để toàn màn hình. Kéo cửa sổ sang màn hình chiếu.
2
Mở màn hình Admin trên máy MC
Double-click 1_Admin_QuaySo.html trên cùng máy tính — giữ cửa sổ này cho MC.
3
Nhấn QUAY SỐ
Admin nhấn nút ▶ QUAY SỐ. Máy quay drum sẽ chạy → dừng lại hiện số thứ tự và tiêu lệnh số. Màn hình LED tự động hiện tên nhân viên, mã số, chức vụ, số tiêu lệnh. Admin thấy đầy đủ cả nội dung tiêu lệnh để theo dõi.
4
Nhân viên đọc tiêu lệnh
Nhân viên được gọi tên đứng lên đọc tiêu lệnh theo số đã quay. Màn hình LED chỉ hiện ô 🔒 CHỜ KẾT QUẢ — khán giả chưa biết nội dung.
5
Admin nhấn Đạt hoặc Chưa Đạt
Admin nhấn ✓ ĐẠT hoặc ✗ CHƯA ĐẠT. Lúc này màn hình LED mới hiện nội dung tiêu lệnh + flash kết quả to cho mọi người thấy.

❓ Câu Hỏi Thường Gặp
Q
Màn hình LED không cập nhật khi Admin quay số?
Kiểm tra xem 2 file có được mở trên cùng một trình duyệt và cùng một máy tính không. Nếu mở trên 2 máy khác nhau thì localStorage không chia sẻ được.
Q
Hiển thị "(Chưa có nội dung tiêu lệnh)"?
Vào File 3 → tab Cài đặt & Reset → nhấn "Khôi phục dữ liệu mặc định" để nạp lại đầy đủ 71 bộ tiêu lệnh.
Q
Muốn chuyển sang máy tính khác?
Vào File 3 → tab Import/Export → xuất JSON nhân viên và tiêu lệnh → copy 4 file HTML + 2 file JSON sang máy mới → import lại dữ liệu.
Q
Muốn xóa lịch sử sau mỗi buổi kiểm tra?
Vào Admin → tab Lịch Sử → nhấn "Xóa Tất Cả". Hoặc vào File 3 → Cài đặt & Reset → "Xóa lịch sử & thống kê".
